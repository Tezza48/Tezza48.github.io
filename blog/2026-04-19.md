## This Website

In short the point of this site is to:

- Serve as a dev log for the many little projects i work on for fun
- Serve as a real (ish) C program that i will need to maintain, improve and scale

So, let's actually talk about how this site is written.

So far, i've implemented a super basic static site generator, it's super minimal, clunky and lazy however it works.


Firstly, there's a linked list based string builder, this is the main feature that makes it work. On top of that ive
got a bunch of macros to make its somewhat simple to hard code some HTML inside the c source code.


Secondly (this is the foundation of the blog) I've added some basic file loading, I'm using this to load a partial
file for <a href="/index.html">index.html</a>, the static content is just an HTML file and in the compiler/generator
i append a preview of the latest post. Additionally the blog post content is loaded from disc and pasted directly
into some hard coded html strings.


Currently the way the blog posts are loaded and even sorted is entirely based on the order that

<code>readdir()</code> returns the files inside the blog folder. As i said it's lazy and probably going to break but it works for now.
There's also no support for markdown yet. I considered writing blog posts in markdown loading them into script tags and
using a third party client side renderer. I've decided not to do that; I would rather approach things like this as
improvements i will make along the way and program myself.


That's all for now. This blog isn't going to be super wordy, I want it to be concise and more of a brain dump.
