For my Dissertation I wrote a Rendering Engine in C++ with DirectX 11. I had originally intended to use DirectX 12 however I quickly realized that it was too big of a task, especially for someone new to rendering.

<!--more-->

The engine features FBX mesh importing via the FBX SDK, Targa image importing (written by myself) and a very basic set of shaders.

In the future I plan to do more work with the engine and possibly write a 3D game using it. The project presented many issues and challenges but I learned so much from working on it and i hope that by continuing to add functionality to it that I will increase my knowledge of Game Engines and engine programming further.
